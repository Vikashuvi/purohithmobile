Purohith Connect Mobile — asset placeholders

Expo needs 4 PNGs to build:
  ./icon.png                (1024×1024)
  ./adaptive-icon.png       (foreground, 1024×1024 on transparent)
  ./splash.png              (2048×2048 recommended)
  ./favicon.png             (48×48 for web export)
  ./notification-icon.png   (Android status bar; 96×96 monochrome)

Add real assets here before your first EAS build. For local `expo start`
development the app runs even without them — Expo will use a default icon
until you drop these in.
